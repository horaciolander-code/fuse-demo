Contenido self-contained listo para desplegar en Vercel (drag & drop en 2 min).

- `index.html` — Hub principal con los 3 agentes
- `sofia.html` — Demo Secretaria WhatsApp + Calendar

- `assets/fuse-api.js` — Cliente LLM (llama al backend Rodmat/Railway)
- `vercel.json` — Config Vercel (cache + rewrites)
